# Ciallo Agent

本地运行的 AI 编程代理，带网页界面。原生 Node.js，零依赖、无需构建。

## 特点

- **中文系统提示词**。我的猜想是中文提示词泛化性更好（因为相关后训练语料大多是英文嘛），目前也没发现生成内容有非常好或者很差。
- **没有多余的提示词**。没有终端敏感词检测，没有安全审查类提示词，也没有让模型绕圈子浪费 token 的规则。好处是省：在都不用子代理的情况下，实测消耗大约是 Claude Code 的 1/3~1/5。坏处是全靠模型自觉，**不建议用小模型跑**。
- **多协议混用**。支持 OpenAI 兼容、Anthropic、Google Gemini 三种协议。上下文用协议无关的内部格式保存，工具名、参数、思考块等会自动映射，所以同一个会话中途可以换成另一种协议的模型接着做。
- **空白发送**。输入框为空时点发送，会把现有上下文原样提交给模型，不追加任何用户消息。断联、出错后重试，或者想让模型接着写时用，不会有"刚才网断了，请继续"这类词污染上下文。
- **按轮删除对话**。可以从上下文里删掉某一轮对话（只改上下文，不回滚文件）。
- **技能和 MCP 都带开关**。随时启用或停用，不用改配置文件。
- **模块化**。每个项目的数据（会话、项目提示词、记忆、项目技能）都存在项目自己的 `.ci/` 目录里。
- **多项目并行**。多个项目可以同时运行，一个项目可以有多个会话（同一项目同一时间只允许一个会话在跑，避免同时改同一批文件）。
- 子代理并行、思考档位、数学公式渲染。

## 上下文管理

大上下文模型容易出现"一口气读一堆文件 → 压缩 → 忘了内容又重读 → 再压缩"的循环，压缩请求本身又不命中缓存，很费钱。这里做了几件事让模型自己知道该怎么读：

- **每轮告诉模型上下文用量**：每批工具结果末尾附一行，例如 `〔上下文 ≈412k / 1000k，再增 ≈338k 自动压缩，压缩后只保留最近 ≈250k 原文〕`。只往后追加，不影响缓存；界面上不显示。
- **文件标注 token 数**：列目录、查找文件的结果里，每个文件后标出完整读取约需多少 token；读文件结果末尾标出本段 token 数。带 `≈` 的是按文件大小估算，不带的是实测值。实测方式：某一轮只读了一个文件时，用前后两次请求的输入 token 差值反推，按文件记在 `<项目>/.ci/tokens.json`。
- **读取警戒线**：读完会让上下文越过警戒线（压缩阈值的 80%），或者这一段比压缩后保留的量还大时，先不读，让模型选：加 `force: true` 确认读取、先压缩、或者暂不读取按已有信息继续。同一轮并行读取会累加计算。
- **压缩只摘要对话**：读文件、列目录的结果在摘要时只留一行记录（读过什么、多少 token），不把内容交给压缩模型；命令、搜索结果压短保留。系统提示词里说明了压缩后不含文件内容。
- **Anthropic 协议历史缓存**：对话历史上打缓存断点，每轮复用上一轮的前缀。

顶部有三个模型选择（会话级）：

| 选择 | 作用 |
|---|---|
| 主模型 | 主代理对话；主代理的压缩阈值按它的配置 |
| 压缩模型 | 只负责生成摘要，主代理和子代理共用；它自己的压缩阈值不起作用 |
| 子代理模型 | 子代理用的模型；子代理的压缩阈值按它的配置 |

压缩模型和子代理模型默认都同主模型。注意上下文长度要和服务端实际上限一致，并给思考预算留出空间（短上下文模型别配高思考档位）。

## 运行

需要 Node.js 22 或更高版本。

```
start.bat                                  # Windows，会请求管理员权限
node src/server.js                         # 其他系统，默认端口 8787
node src/server.js --port 8799 --no-open   # 指定端口，不自动打开浏览器
```

启动后终端会输出带令牌的地址，用它打开。服务只监听 127.0.0.1，令牌每次启动重新生成，可用环境变量 `CI_TOKEN` 固定。

## 配置模型

在网页的"设置 → 模型与供应商"里配置，保存在 `data/config.json`。

1. **添加供应商**：选协议（OpenAI 兼容 / Anthropic 兼容 / Google Gemini），填 Base URL 和 API Key。
2. **添加模型**：填模型 ID，再按实际情况设置：
   - 上下文长度、最大输出、压缩阈值、压缩时保留最近多少 token
   - 子代理并发数
   - 工具风格：原生，或 Claude Code 风格（工具名和参数按 Claude Code 的叫法发给模型）
   - 思考档位：OpenAI、Claude、Google、DeepSeek 官方接口直接选；其他接口选"自定义"，勾选支持的档位并填写每档的请求参数（JSON）

API Key 以明文存在 `data/config.json`，该目录已被 gitignore。

## 技能

技能是一份写给模型的专项指引，模型在任务符合描述时会先读它。

- 全局技能：`skills/<名称>/SKILL.md`
- 项目技能：`<项目>/.ci/skills/<名称>/SKILL.md`

格式：

```markdown
---
name: 名称
description: 一句话说明什么时候用
---

具体说明……
```

可以在"设置 → 技能"里新建、编辑和开关，也可以直接改文件，改动会自动生效。

## MCP

配置写在根目录的 `mcp.json`，格式与常见客户端相同，支持 stdio 和 Streamable HTTP：

```json
{
	"mcpServers": {
		"本地示例": { "command": "npx", "args": ["-y", "某个-mcp"], "env": {}, "enabled": true },
		"远程示例": { "url": "https://example.com/mcp", "headers": {}, "enabled": false }
	}
}
```

也可以在"设置 → MCP"里添加和开关，保存后热更新。MCP 工具默认不发给模型，模型需要时通过工具搜索按需加载，节省上下文。

## 项目设置：提示词、工具开关、记忆

点侧栏项目旁的 ✎ 打开，按项目单独设置：

- **项目提示词**：拼在系统提示词的最前面。
- **工具开关**（默认开）：关掉后不发任何工具，系统提示词也只剩项目提示词，变成纯聊天窗口。
- **记忆库**（默认关）：开启后，记忆写进系统提示词，模型通过 memory 工具自己判断增删改，也可以手动逐条编辑。

这一块主要是拿来和大肥鱼（DeepSeek）聊天用的。注意：记忆拼在系统提示词里，记忆一变缓存就失效，所以编程场景**一般不建议开记忆**。

## 目录

```
src/       服务端：代理循环、协议适配、工具、MCP、技能
web/       网页前端（原生 JS）
skills/    全局技能
data/      配置与项目列表（含 API Key，已 gitignore）
mcp.json   MCP 服务器配置
test/      单元测试（npm test）
```

想让 AI 改这个项目，先让它读 [AGENTS.md](AGENTS.md)。
